# Benchmark evidence (local only)

Run folders written here are git-ignored and never committed; only this README is
tracked. Keep failed, skipped and interrupted attempts: they are part of the
evidence. Archive or copy a run folder elsewhere to keep or share it.

Each folder name identifies its command: `plan` has no model-quality results, and
`run` contains live attempts. A run folder holds a manifest, frozen Project
guidance, source hashes, model checks, exact stage prompts and per-trial evidence:
ordered JSON events, `.bbmodel` snapshots, extracted images, structural
measurements, completion status and an initially unscored review form.

Coding agents: do not search, read or summarize these folders unless the user
points to a specific file.
